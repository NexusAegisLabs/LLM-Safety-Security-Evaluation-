# LLM-Safety-Security-Evaluation-
Comparative LLM safety &amp; security evaluation across hosted &amp; local AI models.

Scope: Comparing hosted models like ChatGPT & Claude versus local models like Qwen, Gemma, & DeepSeek

Methodology: 
-Run the same 10 test prompts across all models.
-Score with a consistent rubric, covering instruction following, factual accuracy, relevance, completeness, safety, and consistency. 
-Compare results and document strengths, weaknesses, and risks.
